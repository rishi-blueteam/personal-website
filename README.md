# R_lgnd Personal Website v2

## Structure
- `html/landing.html` — intro screen
- `html/home.html` — Home page
- `html/certifications.html` — Certifications
- `html/about.html` — About Me
- `html/experience.html` — Experience
- `html/portfolio.html` — Security Portfolio
- `html/contact.html` — Contact
- `css/style.css` — shared design system and responsive layout
- `js/main.js` — shared navigation behavior and landing animation

## Run locally
From the project root, run `python -m http.server 8000`, then open `http://localhost:8000/html/landing.html`.

The terminal messages and Loading line type out. Open Profile appears 2 seconds after Welcome, User finishes. A visible 5, 4, 3, 2, 1 countdown then navigates to Home. Clicking Open Profile goes to About Me. The left-side Blue Team terminal is an illustrative sample, not real monitoring or live alerts.
